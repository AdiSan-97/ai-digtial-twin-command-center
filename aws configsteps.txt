# How to give aws cred to project
1. Create seperate IAM user
2. Save client Id and Secret Key
3. Type : aws configure --profile digital-twin
4. Give Key and Secret , region , output format
5. Test with : aws sts get-caller-identity --profile digital-twin
6. We have to see if the current region has Bedrock enabled or not
check with : aws configure get region --profile digital-twin
7. Lets check our IAM user can talk to Bedrock control panel or not
Check: 
aws bedrock list-foundation-models \
  --region us-east-2 \
  --profile digital-twin
 8. To get only details of FMs available

 aws bedrock list-foundation-models \
  --region us-east-2 \
  --profile digital-twin \
  --query "modelSummaries[].{Provider:providerName,Model:modelName,ModelId:modelId}" \
  --output table \
  --no-cli-pager

9. To get only anthropic models

aws bedrock list-foundation-models \
  --region us-east-2 \
  --profile digital-twin \
  --by-provider anthropic \
  --query "modelSummaries[].{Provider:providerName,Model:modelName,ModelId:modelId}" \
  --output table \
  --no-cli-pager
